PineconeMC Offline - read me first
==================================

Minecraft for computers without internet.

To start:   double-click  pineconemc-offline.exe
            (If Windows says "Windows protected your PC", click
             "More info", then "Run anyway".)

The guide:  in the launcher, press F1 (or click any "?" button).
            It's also in this folder as Guide.html, for any web
            browser (no internet needed).

How games get onto this computer:
  1. On a computer WITH internet, run this same launcher and click
     "Export Bundle". It makes one .zip file.
  2. Copy that file to a USB stick.
  3. On this computer, click "Import Bundle" and pick the file.

Keep this whole folder together: your games, worlds and settings are
stored inside it. To update the launcher, copy the new version's files
INTO this folder (don't delete it first).

You need to own Minecraft: Java Edition. PineconeMC Offline is free
software (GPL-3.0); see Guide.html, section "Legal and credits".
