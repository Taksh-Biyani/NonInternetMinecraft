1. What PineconeMC Offline is

PineconeMC Offline is a Minecraft launcher for computers that have no internet connection. It is based on PineconeMC and Prism Launcher, so it looks and works much like them.

A normal launcher downloads the game the first time you play, which isn't possible without internet. This launcher uses offline bundles instead. A bundle is one .zip file that holds everything a game needs:

  • Minecraft itself;
  • mod loaders such as Fabric or Forge;
  • whole modpacks;
  • the right Java.

You make a bundle on any computer with internet, carry it over on a USB stick, and import it.

Both computers use this same launcher: the online one to make bundles, the offline one to import them.

What you need

  • Windows 10 or Windows 11, 64-bit.
  • Disk space:
    • about 1 GB for the launcher and its Java;
    • about 0.6 GB for each Minecraft version;
    • more for modpacks and worlds.
  • A copy of Minecraft: Java Edition that you own (see Legal).
  • For making bundles: any Windows computer with internet, and a USB stick big enough for the bundle.

Playing together on a local network (LAN) works without internet. See Playing together on LAN.

2. Installing the launcher

There is no installer. The launcher is a folder that runs from wherever you put it, and it keeps everything (games, worlds, settings) inside that folder.

  1. Copy the launcher folder (or unzip the launcher zip) to where you want it:
    • On the computer, for example C:\Games\PineconeMC Offline. This is the fastest.
    • On a USB stick, to carry your games between computers. It works, but games load more slowly from most sticks.
  2. Open the folder and double-click pineconemc-offline.exe.
"Windows protected your PC"? Windows SmartScreen shows this for programs it hasn't seen often. Click More info, then Run anyway. You only need to do this once per computer.
Two kinds of folder cause problems:
  • folders that need administrator rights, such as C:\Program Files;
  • folder names containing !, which confuses Java.

Desktop shortcut: right-click pineconemc-offline.exe → Show more options → Send to → Desktop (create shortcut).

Uninstall: delete the folder. Copy your worlds out first if you want to keep them (see Worlds).

3. First start and player names

The first time you start the launcher, a short welcome wizard opens:

  1. Language, if the launcher can't tell which one you use.
  2. Welcome. A short explanation of bundles. Here you can already make the text bigger or switch on high contrast (see Accessibility).
  3. Player name. The name you have in the game, and the name friends see on LAN.
    • 3 to 16 characters: letters A–Z, digits 0–9 and _. No spaces.
    • The wizard says right away if a name won't work, and why.
    • Leave it empty to skip; you can add a name later.
  4. You're ready. Pick one of these, or just press Finish:
    • Import a bundle
    • Create an instance
    • Open the guide

Accounts

Open Accounts (top right) → Manage Accounts to add more players or switch between them.

  • Offline accounts are just a name:
    • no internet and no password needed;
    • the same name always gets the same player identity, on any computer, so your inventory in a shared world follows your name.
  • Microsoft accounts (and Ely.by accounts) need internet to sign in. Add them on a computer with internet if you want your skin and online servers.

4. Offline mode

When the launcher is offline, it never tries to download anything. It uses only what you've imported from bundles.

A small Offline button at the bottom right of the window shows when this is the case. Click it to open the setting.

The setting is in Settings → Services → Offline mode:

ChoiceWhat it does
Automatic (normal)Checks for internet at start-up, which takes at most a few seconds. With internet the launcher works normally; without it, the launcher is offline.
Always offlineNever checks, never downloads. Good for computers that never have internet.
Always onlineAlways behaves like a normal launcher. Use this on the computer that makes bundles if the automatic check gets it wrong.

What changes when the launcher is offline:

  • Version lists show only versions you've imported. Their Refresh buttons are greyed out.
  • The Modrinth, CurseForge, ATLauncher, FTB and Technic pages show a "You're offline" note instead of a list. Its Refresh button tries again, in case this computer has just been connected.
  • News, update checks and translation downloads are skipped quietly.

Offline mode only affects the launcher. Inside the game, LAN and servers work as usual.

5. Making a bundle on a computer with internet

Do this on a computer with internet, using PineconeMC Offline. Either copy the launcher folder onto that computer, or run it from the USB stick.

  1. Click Export Bundle in the toolbar.
  2. Choose Minecraft versions and mod loaders.
  3. Pick the Minecraft version. Tick Show snapshots if you want test versions.
  4. Pick a Mod loader (Fabric, Quilt, Forge, NeoForge…) and its version, or leave None (vanilla).
  5. Click Add to bundle. Repeat for other loaders or Minecraft versions; they all go into the same file. Loaders for the same Minecraft version share most files, so they add little size.
  6. The right Java for each version is added automatically. Click Next.
  7. On Review, check the list and where the file is saved:
    • if a USB stick is plugged in, the launcher suggests it; otherwise the Desktop;
    • use Browse... to change it.
  8. Click Build bundle. The launcher downloads and packs everything; you can keep using it meanwhile. Cancel stops at any time and leaves nothing behind.
  9. When it says Done!, click Show in folder. That .zip file is your bundle.
How big is a bundle?About
One Minecraft version with its Java0.6 GB
Each extra loader for the same versiona few MB to 40 MB

Wait for the file to finish copying to the USB stick, then use Eject in Windows before you pull it out. A bundle that wasn't copied completely is refused as "damaged" on import.

6. Bundling modpacks (Modrinth and CurseForge)

Modpack websites can't be browsed without internet, so you bring the finished modpack over as a bundle:

  1. On the computer with internet, click Add Instance and choose Modrinth or CurseForge on the left. Find the modpack and install it as usual.
  2. Start it once to check it works. This is optional, but it saves surprises later.
  3. Right-click the new instance → Export → Offline Bundle.
  4. The bundle wizard opens with that instance already chosen. Tick Include worlds (saves) only if you want to take its worlds along too.
  5. Click Next → Build bundle, and copy the file to the USB stick.

The bundle contains:

  • the instance with all its mods, configs and resource packs;
  • the Minecraft version, loader and Java it needs.

On the offline computer, importing it gives you a ready-to-play instance.

The same way works for any instance you've built yourself. On the computer with internet, add mods to it (Edit → Mods → Download mods), then export it as an offline bundle.

7. Importing a bundle

On the offline computer:

  1. Plug in the USB stick.
  2. Click Import Bundle in the toolbar. The file picker opens on the USB stick. Pick the bundle's .zip file.
    Two other ways do the same:
    • drag the .zip onto the launcher window;
    • use Add Instance → Import.
  3. A preview lists what the bundle adds and its size. Things you already have are marked "already installed" and skipped. Click Import.
  4. Wait for the progress bar. The bundle is checked before anything is installed, so a damaged bundle changes nothing.
  5. When it's done:
    • For Minecraft versions and loaders, click Create instance and pick the version.
    • For an instance or modpack bundle, click Play.

Importing never deletes or overwrites your worlds, instances or settings. Importing the same bundle twice is harmless.

Creating an instance from an imported version

  1. Click Add Instance and give it a name.
  2. Pick the Minecraft version. Only imported versions are listed while offline.
  3. On the right, pick a mod loader if you want one.

8. Updating Minecraft or a mod loader

Updating is the same as getting something new: make a bundle with the new version on a computer with internet, and import it. Old versions stay installed, so nothing you have stops working.

Then use the new version in one of these ways:

  • Move an instance to the new version: select it → Edit → Version → select Minecraft or the loader → Change version. Back up your worlds first: a world opened in a newer Minecraft can't go back to an older one.
  • Make a new instance with the new version and copy your worlds into it (see Worlds).
  • Modpacks:
    1. Update the modpack on the computer with internet.
    2. Export it and import it again. It comes in as a new instance next to the old one.
    3. Move your worlds over, and delete the old instance when you're happy.

9. Java

Minecraft needs Java, and different Minecraft versions need different Java versions. The launcher comes with the common ones and picks the right one for each game automatically:

Bundles also include the Java their versions need, so a bundle always brings what it needs.

If a game still can't find a suitable Java, it tells you which one is missing (see files are missing). Make a bundle of that Minecraft version: that adds its Java.

You don't need to install Java on Windows. Leave Settings → Java on automatic unless you know you need something else.

10. Backing up and moving worlds

Each instance keeps its own worlds. Select the instance → Edit → Worlds:

  • View Folder opens the saves folder. Each world is one folder in there.
  • Back up a world by copying its folder somewhere safe, such as another drive or a USB stick. Close the game first.
  • Add brings in a world from a .zip file. You can also copy a world folder into another instance's saves folder.
  • Copy makes a duplicate inside the same instance, handy before trying something risky.

To another computer, either:

  • copy the world folder over on a USB stick and put it in an instance's saves folder there; or
  • export the whole instance as an offline bundle with Include worlds (saves) ticked.
Open a world only in the same Minecraft version or a newer one. Older versions can damage newer worlds.

11. Playing together on LAN

Computers on the same network can play together with no internet. "The same network" means the same Wi-Fi, or connected to the same router or switch.

  1. Everyone uses the same Minecraft version and the same mods. The easiest way: import the same bundle on every computer.
  2. Every player uses a different player name.
  3. The host starts a world, presses Esc → Open to LAN → Start LAN World. The game shows a port number.
  4. The others open Multiplayer. The world usually appears at the bottom after a few seconds. If it doesn't:
    • use Direct Connection and type the host computer's address and the port, like 192.168.1.20:51234;
    • to find the address, on the host press Win+R, type cmd, then type ipconfig and look for "IPv4 Address".
Windows Firewall: the first time a game hosts or joins, Windows may ask whether Java may use the network. Tick Private networks and click Allow access.
If you clicked Cancel by mistake, LAN games won't be found. Ask whoever looks after the computer to allow javaw.exe in the firewall.

12. Updating the launcher

New versions of PineconeMC Offline come as a zip, the same way as the first one. Your instances, worlds, accounts and settings live in the launcher folder, and they are kept.

  1. Close the launcher and any running game.
  2. Make a backup copy of the launcher folder, or at least of its instances folder. It's quick insurance.
  3. Copy everything from the new zip into your existing launcher folder. When Windows asks, choose Replace the files in the destination.
  4. Start pineconemc-offline.exe as usual.

Don't delete the old folder and start fresh: that would lose your games. The update zip contains only program files, never your games or settings.

13. Accessibility

Open Settings → Accessibility. The same options are on the first page of the welcome wizard.

  • Text size: 100% to 200%, for all launcher text.
  • High contrast:
    • Automatic (normal): switches on by itself when Windows' own high-contrast mode is on.
    • On: white text on black, or On: black text on white.
    • High contrast also draws a thick outline around whatever the keyboard is on.

Keyboard

  • Tab and Shift+Tab move between controls. Space or Enter presses a button. Arrow keys move in lists.
  • Underlined letters in labels: press Alt + that letter to jump there.
  • F1 opens this guide.
  • Windows' screen reader, Narrator (Ctrl+Win+Enter), reads the launcher's buttons, fields and messages.

In the game

Minecraft has its own options under Options → Accessibility Settings: narrator, subtitles, text background, high-contrast text, reduced screen effects and more.

The size of the game's menus is set in Options → Video Settings → GUI Scale.

14. Troubleshooting

Every error message in the launcher says what happened and what to do. Most also have a Details section and a Copy details button. Paste those details when you ask someone for help.

Importing a bundle

"This zip isn't an offline bundle…"

The file is a normal zip, a modpack file or an instance export, not a bundle made with Export Bundle.

Modpack files from websites need internet to install. Install the modpack on a computer with internet and export it as an offline bundle (see Bundling modpacks).

"This bundle is damaged or wasn't copied completely…"

The file on the USB stick doesn't match what was written. Usually the stick was pulled out before copying finished.

Copy the bundle to the stick again, use Eject before removing it, and retry. If it keeps happening, try another USB stick, or make the bundle again.

"This bundle was made by a newer version of PineconeMC Offline…"

Update the launcher on this computer first (see Updating the launcher). The new launcher can travel on the same USB stick.

"This bundle tries to put files where a bundle isn't allowed to…"

The file wasn't made by PineconeMC Offline, or was changed afterwards. Nothing was installed. Make the bundle again with Export Bundle.

"Not enough free space on this drive…"

The message says how much space is needed. To fix it, either:

  • free up space: empty the Recycle Bin, or delete instances you don't play; or
  • move the launcher folder to a bigger drive.
"PineconeMC Offline couldn't write to its folder…"

The drive is full, or the folder is read-only (for example inside C:\Program Files, or on a write-protected USB stick). Move the launcher folder somewhere you can write, such as C:\Games.

Making a bundle

"Making an offline bundle downloads everything it needs…"

Making a bundle needs internet. Connect, then try again.

If the computer is connected but the launcher still thinks it's offline, set Settings → Services → Offline mode to Automatic or Always online.

"Couldn't download …"

The internet connection dropped, or a download server didn't answer. Check the connection and click Build bundle again. Files already downloaded are reused.

"Couldn't write the bundle file…"

The USB stick or folder is full or write-protected. Either free up space, or save the bundle to the Desktop with Browse... and copy it to the stick afterwards.

Bundles over 4 GB need a stick formatted as exFAT or NTFS, not FAT32.

"That instance can't be found any more…"

The instance was deleted or renamed while the wizard was open. Pick it again in the list.

Playing

A game says files are missing

See When a game says files are missing.

The game crashes or closes right after starting

Select the instance → Edit → Minecraft Log to read what happened. Common causes:

  • a mod that doesn't fit the Minecraft or loader version: remove the last mod you added;
  • too little memory: raise it under Edit → Settings → Java.

If a modpack worked on the computer you made the bundle on, the cause is usually memory.

Friends can't find my LAN world
  • Check that all computers are on the same network.
  • Check that Windows Firewall allowed Java (see LAN).
  • Try Direct Connection with the host's address and port.

On some school or guest Wi-Fi networks, computers can't see each other at all; a simple router or switch fixes that.

"Invalid session" or "Failed to verify username" when joining

The host is using a Microsoft account while you use an offline name. The host should switch to an offline name (see Which accounts can play together).

I can't join someone else's LAN world, even though everything above is right

This can also be caused by a bug in Minecraft itself. The free OfflineLAN mod works around it. Only the host needs it, and the host's instance must use Fabric.

  1. On a computer with internet, open the host's instance → Edit → Mods → Download mods, search for OfflineLAN and add it.
  2. Export that instance as an offline bundle and import it on the host computer (see Bundling modpacks).
  3. On the host, start the world and press Esc → Open to LAN. Switch Online Mode to OFF, then click Start LAN World. Note the port number the game shows.
  4. The others open Multiplayer → Direct Connection and type the host's address and that port in the form <ip-address>:<port>, for example 192.168.1.20:51234. To find the address, see Playing together on LAN.

When everyone is on the same network, nothing needs to be set up on the router.

The Modrinth or CurseForge page says "You're offline"

That's expected without internet: modpacks can't be browsed. Bring them over as bundles (see Bundling modpacks).

If this computer has internet now, click Refresh on that note.

"Nothing is installed for this yet" in a version list

No bundle with that Minecraft version or loader has been imported on this computer. Make and import one (see Making a bundle).

15. When a game says files are missing

Before a game starts without internet, the launcher checks that everything it needs is on this computer. If something isn't, a window titled "Can't start …" lists what's missing in plain words, for example:

  • Minecraft 1.21.1 or Fabric Loader 0.19.5: that version was never imported here.
  • The Minecraft 26.3 game file or N game library files: parts of the game are missing.
  • Minecraft 26.3 sounds and textures: the game's assets are missing.
  • Java 25: no Java on this computer can run this version.

The fix is always the same:

  1. On a computer with internet, make a bundle with that Minecraft version (and the loader, if one is listed). Or export the instance itself as an offline bundle.
  2. Click Import Bundle... right in that window (or on the toolbar) and pick the file.
  3. Start the game again.

How it usually happens:

  • An instance was copied from another computer without its Minecraft version. Export it as an offline instance bundle instead, which carries everything.
  • An instance's version was changed (Edit → Version) to one that isn't imported.
  • Files were deleted from the launcher's libraries, assets or java folders.

Details in that window lists every missing file, if someone helping you wants to see them.
